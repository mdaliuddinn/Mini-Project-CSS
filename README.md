# Mini CSS Project 🚀

A simple CSS-based mini project created to practice frontend fundamentals like layout, styling, and responsiveness.

## 🔧 Technologies Used
- HTML5
- CSS3

## ✨ Features
- Clean UI layout
- CSS styling and hover effects
- Beginner-friendly structure
- Toggle functionality using `input type="checkbox"`
- Smooth animations using CSS transitions and transforms
- Hover-based visual feedback
- Cursor interaction for better UX
- No JavaScript used (CSS-only interaction)

**Completed**

- Using Git & GitHub workflow

- Implemented the checkbox hack for interactivity
- Improved understanding of CSS animations and pseudo-classes
